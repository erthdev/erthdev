# About

**Networking Dragons** is an open source documentation project dedicated to restoring, modifying, reverse engineering, and creating networking hardware.

Instead of allowing old routers, switches, access points, and embedded networking devices to become electronic waste, this project explores how they can be repaired, reconfigured, upgraded, and documented for educational purposes.

Every completed project becomes a **Dragon**, representing not only the hardware itself, but also the engineering journey behind it.

Networking Dragons combines:

- Networking
- Linux
- Embedded Systems
- Hardware Repair
- Reverse Engineering
- Documentation
- Open Source Collaboration

---

# Why Dragons?

Throughout history, dragons have symbolized many things.

- Wisdom
- Power
- Guardianship
- Ancient knowledge
- Transformation
- Perseverance

Networking hardware shares an interesting similarity.

Routers quietly protect our networks.

Firewalls guard our homes.

Switches silently connect devices.

Access points provide invisible communication.

Like dragons, they work continuously in the background, often unnoticed until they are gone.

When an old router reaches the end of its official support, many people discard it.

Networking Dragons believes every piece of hardware still has a story to tell.

Each restored device earns its own dragon identity because every project is unique.

No two dragons are the same.

---

# Philosophy

Networking Dragons follows a simple philosophy.

> **Repair before replacing. Learn before modifying. Document before forgetting. Share before discarding.**

Every project aims to answer questions such as:

- Can this hardware still be useful?
- Can hidden features be unlocked?
- Can firmware limitations be overcome?
- Can performance be improved?
- Can someone else learn from this journey?

The documentation is considered just as valuable as the final result.

# Design Principles

Networking Dragons follows several core principles.

## Sustainability

Working hardware should not become electronic waste simply because official support has ended.

---

## Transparency

Every modification is documented.

No undocumented changes.

---

## Learning

The objective is not merely to make hardware function.

The objective is to understand why it works.

---

## Open Source

Documentation belongs to everyone.

Knowledge improves when shared.

---

## Engineering

Projects are approached as engineering case studies rather than simple hardware modifications.

# Current Dragons

## 🐉 White Dragon

**Platform**

Huawei EchoLife EG8145V5

**Mission**

Restore an ISP locked GPON terminal and transform it into a fully functional wired wireless access point.

Completed:

- Hardware restoration
- Antenna repair
- Administrator access recovery

- Custom enclosure redesign
- White Dragon themed restoration

Future work:

- Thermal optimization
- Internal cooling
- Firmware research
- UART documentation

## 🐉 Emerald Dragon

**Platform**

Converge Xperience Hub  
ZTE ZXV10 B886V2F  
Amlogic S905Y4

**Mission**

Repurpose an ISP issued IPTV platform into a dedicated home media hub while documenting its hardware, firmware, boot process, and reverse engineering limitations.

Completed:

- Hardware identification
- Amlogic S905Y4 platform investigation
- eMMC storage identification
- MaskROM test point investigation
- Boot process investigation
- Firmware research
- Custom firmware feasibility assessment
- Android TV media hub deployment
- Plex installation and configuration
- Emerald Dragon themed redesign

Future work:

- Expand local media storage
- Hardware documentation
- Board and test point documentation
- Continued firmware research
- Further exploration of the S905Y4 platform

# Inspiration

Networking Dragons was inspired by a simple observation.

Old networking hardware is rarely broken.

More often, it is simply forgotten.

This project exists to prove that forgotten hardware can still teach valuable lessons.

Every Dragon is a reminder that engineering is not only about creating new technology.

Sometimes, it is about giving existing technology a second chance.
